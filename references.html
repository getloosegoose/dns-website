DNS research sources

These are the sources for the DNS information in my project. The RFCs explain the technical details. If you are new to DNS, start with the ICANN or Cloudflare pages. Links were checked on October 20, 2026.

  1. RFC 1034: Domain Names — Concepts and Facilities

    Foundational explanation of DNS organization, resolvers, and name servers.

  2. RFC 1035: Domain Names — Implementation and Specification

    Record formats, queries, and responses. These foundational RFCs have later updates.

  3. RFC 3596: DNS Extensions to Support IP Version 6

    Defines the AAAA record for IPv6 addresses.

  4. RFC 2308: Negative Caching of DNS Queries (DNS NCACHE)

    Explains caching of negative DNS answers.

  5. RFC 4033: DNS Security Introduction and Requirements

    DNSSEC protections, goals, and limitations.

  6. RFC 7858: Specification for DNS over Transport Layer Security (TLS)

    Specification for encrypted DNS transport using TLS.

  7. RFC 8484: DNS Queries over HTTPS (DoH)

    Specification for carrying DNS messages through HTTPS.

  8. ICANN: About Domain Names

    An accessible introduction to domain names and their organization.

  9. Cloudflare Learning Center: What is DNS?

    A beginner explanation of resolvers and the lookup process.

  10. Cloudflare Learning Center: What is DNS cache poisoning? | DNS spoofing

    Explains false DNS answers and their effects.
