A beginner's guide to the Domain Name System

Seven Key Concepts

Seven DNS ideas with examples to help explain them.

01

The DNS hierarchy

DNS names are organized in levels. In www.example.com, com is the top-level domain, example is below it, and www is another label. The root sits above the top-level domains.

Example: Read a name from right to left to understand its place in the hierarchy.

02

Recursive and iterative lookups

A recursive request asks the resolver to find an answer for the client. In an iterative lookup, a server may point the resolver to another server to keep looking.

Example: Your device asks for an answer; the resolver follows referrals on your behalf.

03

Authority and delegation

An authoritative server provides the official DNS records for a zone. Delegation means giving other name servers responsibility for part of the DNS naming system.

Example: The .com zone delegates example.com to its designated authoritative servers.

04

Caching and TTL

Caching temporarily stores answers. A record’s time to live (TTL), measured in seconds, controls how long it may normally be reused from cache.

Example: A TTL of 300 allows caching for up to five minutes. Existing cached answers may remain after an administrator changes a record.

05

Aliases and addresses

An alias points to another name. Address records connect a name with IPv4 or IPv6 addresses.

Example: A CNAME for www.example.com can lead to example.com; an address lookup then needs the target’s A or AAAA records.

06

Negative answers

NXDOMAIN means the queried name does not exist. A name may also exist without the requested record type. Negative answers can be cached.

Example: An existing hostname might have an A record but no AAAA record; that is different from a nonexistent hostname.

07

Validation and encryption

Validation checks DNS data. Encryption protects a communication channel. These protections can work together.

Example: A resolver can use DNSSEC to validate an answer while your device uses DoH to communicate with that resolver.
