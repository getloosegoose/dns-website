DNS Basics

Learn what happens during a DNS lookup and what the main records do.

What happens when you enter a name?

Your device sends its DNS question to a recursive resolver. This service looks for the answer for you. It first checks whether it has a saved answer it can still use. If it does not, it can ask other name servers.

  1. Ask the resolver. The client requests a record, such as the A record for www.example.com.
  2. Start at the root. A root server refers the resolver to servers for the relevant top-level domain, such as .com.
  3. Ask the TLD server. It provides a referral to authoritative servers for the domain.
  4. Ask an authoritative server. This server publishes records for its zone and can return the requested data.
  5. Return the result. The resolver answers the client and can cache records for later requests.

Queries and responses

A DNS query is a question about a name and a record type. The reply may give an answer, point to another server, or report an error. A records give IPv4 addresses, while AAAA records give IPv6 addresses. Once the browser has an address, it can connect to the web server. DNS finds the address; it does not download the webpage.

A practical example

When you visit www.ksu.edu, your device needs to resolve that hostname. It may receive IPv4 addresses, IPv6 addresses, or an alias that requires another lookup. Answers can change, so this example intentionally does not claim a current KSU IP address.
